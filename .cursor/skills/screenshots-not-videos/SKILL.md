# Screenshots, not videos

- **Never record a video** (screen recordings, GIFs, browser recordings) unless the user explicitly asks for one.
- **Always show screenshots** of visual work: take them after UI changes or browser testing and embed them inline in the reply with `![description](/absolute/path/or/url)`.
- Skip screenshots only when the user says not to.
